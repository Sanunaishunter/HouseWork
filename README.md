# 🏡 家事紀錄表 HouseWork

活潑配色、拖拉式方塊模組的家事紀錄網頁。純前端（HTML / CSS / JavaScript），無需安裝或建置，資料儲存在瀏覽器的 `localStorage`。

## 功能

- **🧩 打卡看板**：點擊月曆上的日期，下方會顯示當天已記錄的項目；點擊「＋ 新增任務」展開方塊區，再拖曳（或點擊）方塊記錄到該天。
  - 預設方塊：洗衣、早餐、中餐、晚餐、掃地、拖地、被罵、看病、帶出門去玩、上班、副業、信用卡遲繳
  - 「被罵」、「看病」方塊會跳出視窗，讓你手動輸入備註（memo）
- **📜 歷史紀錄**：依日期分組顯示所有紀錄，可依項目篩選、關鍵字搜尋備註
- **📊 統計摘要**：總紀錄數、今日紀錄、被罵次數、近 7 天趨勢圖、各項目累計次數長條圖
- **💾 資料管理**：匯出 JSON / CSV、匯入還原、清除全部資料
- **🔒 密碼彩蛋 + 登出（煙霧彈）**：畫面右上角有一塊完全隱形的熱區，滑鼠移過去（或手指點到）才會悄悄啟動密碼輸入功能，沒有任何文字或框線提示；輸入正確密碼會短暫顯示「✓」並恢復顯示（純前端字串比對，屬於小互動巧思，不是真正的存取控制）。「資料管理」分頁的「登出」只是把整個看板收起來變成空白畫面的煙霧彈，不會刪除任何紀錄，重新用該熱區輸入密碼就能拿回一模一樣的內容

## 使用方式

直接用瀏覽器開啟 `index.html` 即可使用，或用簡易伺服器啟動：

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

## 資料匯出

匯出的檔案請手動移動保存到 [`SaveData/`](./SaveData) 資料夾，之後可透過「資料管理」分頁的匯入功能還原。

## 專案結構

```
HouseWork/
├── index.html          # 主頁面
├── css/style.css        # 活潑配色樣式
├── js/app.js             # 拖拉互動 / 分頁 / 資料邏輯
├── SaveData/             # 匯出資料存放處
└── README.md
```
