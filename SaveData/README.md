# SaveData

這個資料夾用來存放從「資料管理」分頁匯出的家事紀錄檔案（JSON / CSV）。

## 使用方式

1. 在網頁的「💾 資料管理」分頁點擊「匯出 JSON」或「匯出 CSV」。
2. 瀏覽器會把檔案下載到系統的下載資料夾，檔名格式為 `housework-export-<時間戳記>.json` 或 `.csv`。
3. 手動將下載好的檔案移動到這個 `SaveData/` 資料夾保存或備份。
4. 之後可以在「資料管理」分頁使用「匯入資料」功能，選取這裡保存的 JSON 檔案來還原紀錄。

> 這個資料夾預設不會被自動寫入（純前端網頁基於瀏覽器安全限制無法直接寫入本機資料夾），僅作為你手動保存匯出檔案的地方。
